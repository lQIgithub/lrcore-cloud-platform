# LRCore Cloud Platform 规则文档索引

## 文档概述

本文档作为 LRCore Cloud Platform 项目规则文档的主入口，提供所有规则文件的导航和摘要信息。

---

## 规则文档目录

### 1. 版本依赖保护规则
- **文件**: [rules-version.md](./rules-version.md)
- **功能**: 定义前后端依赖版本管理规则，确保项目依赖的稳定性和一致性
- **适用范围**: 所有开发人员、测试人员、运维人员

### 2. 后端开发规范
- **文件**: [rules-backend.md](./rules-backend.md)
- **功能**: 定义后端服务开发的完整规范，包括模块结构、代码风格、配置规范等
- **适用范围**: 后端开发人员

### 3. 前端开发规范
- **文件**: [rules-frontend.md](./rules-frontend.md)
- **功能**: 定义前端项目开发的技术栈、代码风格和开发流程
- **适用范围**: 前端开发人员

### 4. 部署与运维规范
- **文件**: [rules-deployment.md](./rules-deployment.md)
- **功能**: 定义服务部署流程、环境配置、监控维护和终端使用管理规则
- **适用范围**: 运维人员、开发人员

### 5. 安全规范
- **文件**: [rules-security.md](./rules-security.md)
- **功能**: 定义认证授权、数据安全、接口安全等安全相关规则
- **适用范围**: 所有开发人员、运维人员

### 6. 文档规范
- **文件**: [rules-document.md](./rules-document.md)
- **功能**: 定义技术文档和代码注释的编写规范
- **适用范围**: 所有开发人员

### 7. SQL Schema 规范
- **文件**: [rules-sql.md](./rules-sql.md)
- **功能**: 定义数据库 Schema 文件的生成规范，明确主键 ID 使用 BIGINT(20) 数据类型
- **适用范围**: 后端开发人员、数据库设计人员
